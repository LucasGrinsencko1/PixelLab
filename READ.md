
# PixelLab 🎨

A lightweight and interactive pixel art editor built with
HTML, CSS, and vanilla JavaScript.

Create pixel artwork directly in your browser and export
your creations as PNG images.

## Features

- Interactive 16x16 drawing grid
- Pencil and eraser tools
- Eight-color palette
- Click-and-drag drawing
- Clear canvas functionality
- PNG export (320x320 resolution)
- Responsive dark-themed interface

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- Canvas API

## Getting Started

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No external dependencies are required.

## How to Use

1. Select a color from the palette.
2. Use the Pencil tool to draw.
3. Select Eraser to remove individual pixels.
4. Click Clear Canvas to reset your artwork.
5. Click Export PNG to download your creation.
